# 포탈 월드 — 바뀐 내용

## 0.2.0 — 그래픽 개선
- 캐릭터를 여전사로 교체 (강철 흉갑·어깨 갑옷·건틀릿·그리브, 붉은 장발, 망토, 등에 검)
- 지형에 실사 텍스처 (Poly Haven CC0: 풀·바위·모래·눈·나무껍질) — 경사·높이·물가에 따라 자동으로 섞어 칠함
- HDRI 하늘·환경광 (세계마다 다른 하늘), 실시간 그림자, 물결 애니메이션
- 풀잎 수천 개, 바위·나무껍질 텍스처, 세계별 나무 모양(선인장·침엽수·활엽수)

## 0.1.0 — 첫 빌드
- 넓은 3D 세계 4개 (초록 평원 · 붉은 사막 · 하얀 설원 · 보랏빛 심연), 낮밤 순환
- 여성 모험가 캐릭터, 조이스틱 이동·점프·시야 회전
- 채집(나무·바위·덤불·광맥·수정·풀) → 제작(도끼·곡괭이·횃불·모닥불·오두막·포탈 조각·포탈) → 설치
- 포탈을 세우고 들어가면 다음 세계 (왕복 포탈 자동 생성)
- 점수·레벨, 자동 저장, 로그인하면 서버 저장·랭킹
